# Tetris Game

A fully functional Tetris game built entirely by a local AI model (qwen3.6-35b-a3b) using `opencode` CLI.

## Features

- Complete Tetris gameplay with all standard pieces
- Ghost piece preview (semi-transparent)
- Next piece preview
- Score tracking and level progression
- Comprehensive test coverage (160+ tests)

## Tech Stack

- React + TypeScript
- Vite
- Vitest for testing

## Running the Game

```bash
npm install
npm run dev
```

## Running Tests

```bash
npm test
```
